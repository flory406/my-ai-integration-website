## Про проєкт

FlorySite — це односторінковий застосунок (SPA) із повноцінним багатосторінковим
маркетинговим сайтом: головна, можливості, про нас, ціни, блог і контакти. Це перший
із серії шаблонів-лендінгів, зроблений так, щоб його було легко перефарбувати,
локалізувати й переносити блоки між проєктами.

Візуальна мова: майже чорне тло, теплі помаранчеві акценти, «скляні» картки
(glassmorphism), м'яке світіння та акуратний рух. На головній — велика AI-ілюстрація,
що працює фоном усієї сторінки й плавно «заходить за горизонт» під час скролу
(темнішає, зміщує колір і згасає).

## ✨ Можливості

- **7 маршрутів** — Home, Features, About, Pricing, Blog, окрема сторінка статті, Contact.
- **Дві мови (EN / UA)** — миттєве перемикання без перезавантаження, вибір зберігається
  в `localStorage`, за замовчуванням береться мова браузера.
- **Анімований фон головної** — AI-свірл на всю сторінку з scroll-ефектом «заходу сонця»
  (Framer Motion `useScroll` + `useTransform`).
- **Анімації** — поява секцій при скролі, нескінченна стрічка логотипів, hover-ефекти,
  плавні переходи.
- **Згенеровані візуали** — тематичні SVG-обкладинки для статей блогу (свій колір та
  іконка під кожну категорію), «скляний» мокап дашборда зі спарклайнами й бар-чартом.
- **Адаптивність** — від десктопа до телефона, повноекранне бургер-меню з суцільним тлом.
- **Інтерактив** — тарифи з перемикачем «місяць/рік» і FAQ-акордеоном, форма контактів
  із фронтовою валідацією (демо — реально нічого не надсилає).
- **Дизайн-токени** — уся палітра, шрифти й відступи винесені в один файл для швидкого
  ребрендингу.

## 🚀 Запуск

```bash
npm install
npm run dev      # дев-сервер на http://localhost:5173
npm run build    # продакшн-збірка у dist/
npm run preview  # локальний перегляд зібраного
```

Потрібен Node.js 18+.

## 📁 Структура

```
src/
  main.jsx            роутер + провайдер мови + підключення стилів
  App.jsx             layout (Navbar + Outlet + Footer), скрол угору при зміні сторінки

  i18n/
    dict.js           усі тексти сайту двома мовами (en + uk)
    LanguageContext.jsx  провайдер мови + хук useLang()

  data/

  styles/

    globals.css       reset + базові примітиви (card, badge, grad-text)
    buttons.css       кнопки
    layout.css        navbar, footer, logo, перемикач мови
    home.css          секції головної + фон-свірл + дашборд-мокап
    pages.css         внутрішні сторінки + обкладинки блогу

  components/          Button, Icon, Logo, Navbar, LangToggle, Footer, Reveal,

  sections/           Hero, LogosMarquee, ShowcaseCards,
```

## 🌐 Локалізація

Усі рядки живуть у `src/i18n/dict.js` (об'єкти `en` і `uk`). Компоненти беруть тексти
через хук:

```jsx
import { useLang } from "./i18n/LanguageContext.jsx";

function Example() {
  const { t, lang, setLang } = useLang();
  return <h1>{t.hero.title1}</h1>;
}
```

Щоб **додати мову** — додайте новий об'єкт у `dict.js`, впишіть код мови в `LANGS`
і, за потреби, кнопку в `components/LangToggle.jsx`.

## 🎨 Як перефарбувати під новий сайт

1. **Палітра й шрифти** — `src/styles/theme.css` (`--accent`, `--accent-grad`,
   `--font-display`, `--bg`…).
2. **Назва бренду** — `BRAND` у `src/data/site.js`.
3. **Тексти** — `src/i18n/dict.js` (обидві мови).
4. **Фонова ілюстрація головної** — заміни `src/assets/hero-swirl.png`.
5. **Секції** — додавай/прибирай блоки у відповідних файлах `sections/` та `pages/`.

## 📝 Нотатки

- Шрифти підключені в `index.html` через Google Fonts.
- `node_modules` і `dist/` навмисно не в репозиторії — відновлюються через `npm install`
  та `npm run build`.
- Форма Contact і поле email на головній валідуються на фронті, але бекенду не мають
  (це демо).
- Контент (назви компаній, тарифи, пости, команда) — вигаданий, для демонстрації.

## 📦 Деплой

Проєкт — звичайний Vite-SPA, тож деплоїться будь-де (Vercel, Netlify, GitHub Pages):
команда збірки `npm run build`, тека з результатом `dist/`. Для SPA-маршрутизації
налаштуйте fallback усіх шляхів на `index.html`.
